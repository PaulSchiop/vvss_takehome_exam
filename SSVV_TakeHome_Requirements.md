# SSVV Take-Home Exam Requirements

## Overview
This take-home exam is for **Application Development and Testing** and is worth a maximum of **900 XP**.[file:1]

## Team requirement
- Create a team of **5 members**, with a maximum of **6 members** allowed.[file:1]
- Add the team in the document located at **General -> Shared -> ExamTakeHome_Teams**.[file:1]

## Assignment structure
The take-home exam has **3 tasks**, each worth **300 XP**, for a total of **900 XP**.[file:1]

| Task | Topic | XP | What is required |
|---|---|---:|---|
| 1 | App Development | 300 | Build the application and provide proof it works.[file:1] |
| 2 | Testing I | 300 | Apply BBT, WBT, and Integration Testing, then submit documentation and test code.[file:1] |
| 3 | Testing II | 300 | Apply Inspection/Review, Exploratory Testing, and GUI/Web Testing, then submit documentation and test code.[file:1] |

## Task 1 requirements
For **Task 1: App Development**, the application must include:[file:1]
- **3 CRUD entities**.[file:1]
- **1 functionality that uses all 3 entities**.[file:1]
- **1 functionality to generate a report on specific information**.[file:1]
- Use of **MVC, etc.**[file:1]

### Task 1 deliverables
Submit:[file:1]
- The **source code**.[file:1]
- A **5-minute video** showing the application running and demonstrating the implemented functionalities.[file:1]

## Task 2 requirements
For **Task 2: Testing I**, apply the following testing techniques:[file:1]
- **BBT** (Black-Box Testing).[file:1]
- **WBT** (White-Box Testing).[file:1]
- **Integration Testing**.[file:1]

### Task 2 deliverables
Submit:[file:1]
- A **summary document** with all testing techniques applied.[file:1]
- The **documents specific to each testing technique**.[file:1]
- The **test code**.[file:1]

## Task 3 requirements
For **Task 3: Testing II**, apply the following techniques:[file:1]
- **Inspection/Review**.[file:1]
- **Exploratory Testing**.[file:1]
- **GUI/Web Testing**.[file:1]

### Task 3 deliverables
Submit:[file:1]
- A **summary document** with all testing techniques applied.[file:1]
- The **documents specific to each testing technique**.[file:1]
- The **test code**.[file:1]

## Dates
- **Assignment date:** seminar 1 (lecture 3).[file:1]
- **Delivery date:** one day before the scheduled exam for each group, at **20:00**.[file:1]
- The sheet states this is both the **first and last** delivery moment for the group submission.[file:1]

## Submission format
Upload to Teams **one archive** with the naming pattern:[file:1]

```text
ExamTakeHome_93X_Name01Name02Name03Name04Name05.zip
```

The archive must contain:[file:1]
1. The artifacts and documents for **Task 1**.[file:1]
2. The artifacts and documents for **Task 2**.[file:1]
3. The artifacts and documents for **Task 3**.[file:1]
4. A **file with the list of team members**.[file:1]

## Important submission rules
- **No guest name** is allowed in the team/member list.[file:1]
- Every person mentioned as a collaborator **must contribute**.[file:1]
- **One member** should upload the assignment.[file:1]
- In the teams document, mention **which student will upload the assignment**.[file:1]

## Study references
The assignment references the following course materials:[file:1]
- **Lectures 1–12**.[file:1]
- **Seminars 1–6**.[file:1]
- **Laboratories 1–6**.[file:1]

## Example application idea
An example project is **Administer family budget – member**, a software system that helps a community such as a family manage and plan a budget.[file:1]

The example application should allow:[file:1]
- Adding a new member of the community, including monthly income contribution and generated costs.[file:1]
- Adding a new budget entry, either **income** or **cost**.[file:1]
- Listing the evolution of incomes/costs for a member.[file:1]

## Practical checklist
Use this checklist before submitting:[file:1]
- Team created and added to the shared teams document.[file:1]
- Team has 5 members, or at most 6.[file:1]
- App includes 3 CRUD entities.[file:1]
- App includes one feature involving all 3 entities.[file:1]
- App includes one reporting feature.[file:1]
- MVC structure is used.[file:1]
- Source code is included.[file:1]
- 5-minute demo video is included.[file:1]
- Testing I documents and code are included.[file:1]
- Testing II documents and code are included.[file:1]
- Team member list file is included.[file:1]
- Archive name follows the required pattern.[file:1]
- The designated uploader is mentioned in the teams document.[file:1]
- Upload is done on Teams before **20:00**, one day before the scheduled exam.[file:1]
